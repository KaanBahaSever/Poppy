Try it right here

Drag a file. Tap a key.

This is a little Windows desktop. Grab a file, and while you hold it tap Shift, Ctrl or Alt. Drop it on a petal.

Three rings

One gesture, everything you do with files

Tap another key while the ring is open to switch. Esc closes it. Results are saved next to the original, and Poppy never overwrites a file.

Shift Convert

PNG, WEBP, AVIF, HEIC, MP3, MP4, PDF, DOCX and more

Ctrl Tools

Compress, trim, crop, edit, redact, merge, protect

Alt Actions

Share, shelf, copy, move, copy path, terminal, zip

What it can do

Every file you drag has a ring
